# AgriMet Network Representativeness

Public story map summarizing two University of Idaho studies of the U.S. Bureau of Reclamation AgriMet network in the Pacific Northwest: spatial adequacy of reference evapotranspiration (ETref) estimation, and representativeness of station surroundings (station aridity).

Supported by the Idaho Water Resources Research Institute at the University of Idaho, through funds appropriated by the Idaho Legislature.

This is a static site (`index.html` plus `assets/`), generated from the project's build scripts; edit the source template there rather than this file. Photo and image credits are listed in the page footer.
